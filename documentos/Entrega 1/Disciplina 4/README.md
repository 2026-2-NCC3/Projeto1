# Entrega 1 – Projeto Interdisciplinar

## Projeto
Próxima Etapa – App do Aluno

## Funcionalidade entregue
Aplicativo Android para visualização dos cursos disponíveis e de seus detalhes.

O aplicativo consulta os cursos por meio de uma API REST, que se comunica com um banco de dados PostgreSQL.

## API publicada
https://proxima-etapa-api-ncc3.onrender.com

## Rota de cursos
https://proxima-etapa-api-ncc3.onrender.com/courses

## Arquivos do projeto
- Aplicativo Android: `src/frontend`
- Backend/API: `src/backend`
- Banco de dados: `src/database`
- APK: `ProximaEtapa-Entrega1.apk`

## Tecnologias
- Java
- Android Studio
- Node.js
- Express
- PostgreSQL
- Supabase
- Render

## Status
Aplicativo, API e banco de dados integrados e funcionando.
