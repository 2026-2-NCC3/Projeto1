## Acesso para avaliação

[Orientações de acesso e avaliação](ACESSOS.md).

Backend existente: [API Próxima Etapa](https://proxima-etapa-api-ncc3.onrender.com/). A consulta de cursos respondeu HTTP 200 na verificação de 16/11/2026. As rotas novas de encontros ainda precisam ser publicadas e testadas nesse ambiente.

O painel administrativo está configurado localmente para acessar esse backend. Não há URL pública confirmada para a versão atual do painel. As tabelas de encontros foram criadas e validadas no Supabase, mas isso não substitui o teste do fluxo completo com painel, API e aplicativo.

O APK presente nesta pasta é uma versão anterior: a compilação e a validação de um APK com as alterações recentes de encontros estão pendentes.

As contas de avaliação devem ser fornecidas aos professores por canal privado. Não incluir senhas, chaves ou o arquivo `.env` neste README.
